# ScreenBridge

عرض شاشة هاتف أندرويد على جهاز أندرويد آخر (تلفاز/هاتف) عبر كابل USB، والتحكم بالفأرة والقبضة والكيبورد،
مع إطفاء لوحة الهاتف دون إيقاف GPU. يعتمد على سيرفر scrcpy الرسمي (يُحمَّل أثناء البناء).
**التطبيق يُثبَّت على الـViewer فقط.**

## البناء
1. ارفع كل الملفات (بما فيها المجلد المخفي `.github`) إلى مستودع GitHub، الفرع main.
2. تبويب Actions ← Build APK ← بعد النجاح حمّل ScreenBridge-debug من Artifacts.

## الإعداد على الهاتف (مرة واحدة)
- خيارات المطوّر ← تصحيح USB. في شاومي فعّل أيضًا "تصحيح USB (إعدادات الأمان)".
- عند أول اتصال وافق على مفتاح RSA.

## الاستخدام
- الكابل من منفذ USB في التلفاز إلى الهاتف، ثم "اتصال".
- الشريط العلوي: ⏻ إطفاء الشاشة، ⟳ تدوير قسري، ⋯ الأدوات، ✕ فصل.
- العودة من الإطفاء: زر الباور في الهاتف أو فصل الكابل. أو ضغط Select+Start لمدة 1.5 ثانية لإطفاء الشاشة من القبضة.
- القبضة: "قبضة حقيقية" (UHID) أو "ربط باللمس" (حدّد التخطيط من الأدوات). التخطيط يُحفظ لكل اتجاه شاشة ولكل ملف (1 إلى 3).
- وضع FPS: يلتقط الفأرة، WASD للحركة، والكاميرا بالفأرة. اربط FIRE وAIM في التخطيط. للخروج: Esc أو الزر الجانبي الأمامي للفأرة.
